# TableDb 

Часткова реалізація системи управління табличними базами даних, варіант 41.
Додаткові типи полів — `enum` та `email`, основна операція — пошук рядків за
шаблоном із символами `*` і `?`.

Робота виконана у двох версіях, які спираються на спільну бібліотеку доменної
логіки `TableDb.Core`.

## Етапи

| Тека | Зміст | Стек |
|---|---|---|
| [`Етап2_Desktop`](Етап2_Desktop) | Десктопна версія з повним інтерфейсом і модульними тестами (37 тестів) | C# / .NET 10, Windows Forms, xUnit |
| [`Етап3_Web`](Етап3_Web) | Веб-версія: REST API та клієнт у браузері | C# / .NET 10, ASP.NET Core Minimal API, HTML/CSS/JS |

У кожній теці є власний README із докладним описом, звіт у форматі `.docx`
та скриншоти інтерфейсу.

## Запуск

Десктопна версія:

```
cd Етап2_Desktop
dotnet run --project TableDb.Desktop
```

Веб-версія:

```
cd Етап3_Web
dotnet run --project TableDb.Web
```

Тести десктопної версії:

```
cd Етап2_Desktop
dotnet test
```

## Спільна частина

`TableDb.Core` містить модель даних (база → таблиця → стовпці й рядки),
ієрархію типів полів, перетворення шаблону пошуку на регулярний вираз і
збереження бази у JSON. Обидві версії використовують її без змін, тому
результати пошуку та правила валідації в них однакові.
