# TableDb — десктоп-версія (Етап 2)

СУ табличними базами даних, варіант 41: типи `enum` та `email`, пошук рядків за шаблоном (`*`, `?`).
C# / .NET 10, Windows Forms (без HTML/CSS).

## Запуск

```
dotnet run --project TableDb.Desktop
```

Демонстраційна база: «Файл → Відкрити…» → `samples/Університет.tdb.json`.

## Тести

```
dotnet test
```

## Структура

- `TableDb.Core` — модель, типи даних, валідація, пошук, збереження у JSON
- `TableDb.Desktop` — графічний інтерфейс (MainForm, CreateTableForm, RowEditForm, SearchResultsForm)
- `TableDb.Tests` — unit-тести xUnit (37 тестових випадків)
- `screenshots/` — знімки екрана для звіту

## Робота з віддаленим сервером (бонусна частина)

Окрім локальних файлів, десктоп-клієнт уміє працювати з базами на сервері
TableDb Web (етап 3). Меню **Сервер**:

- **Підключитися до сервера…** — адреса, типово `http://localhost:5000`;
- **Відкрити базу з сервера…** — список баз сервера, вибрана завантажується через `GET /api/databases/{db}/export`;
- **Зберегти на сервері** — надсилає базу через `PUT /api/databases/{db}`; те саме робить Ctrl+S, якщо база прийшла із сервера.

Технічно це друга реалізація того самого інтерфейсу `IDatabaseStorage`
(`RemoteDatabaseStorage`), тому решта програми не знає, звідки саме взялася база.
